# 位相方程式からのSDE生成・CPU推定サンプル

同梱の位相方程式を読み込み、2系の位相SDEをシミュレーションし、そのデータから
空間・時間のドリフトとノイズ共分散をCPUで推定する。
既存の論文用コード・データ・推定結果は変更しない。このフォルダをコピーすれば単独で実行できる。

## 実行

既存の `torus2025-dev` 環境で、リポジトリのルートから次を実行する。

```sh
conda activate torus2025-dev
python 推定サンプルプログラム/run_sample.py --overwrite
```

`--overwrite` が更新するのは、指定した出力先のこのサンプルの出力ファイルだけ。
既存ファイルを残す場合は、別の `--output-dir` を指定する。
新しい環境には Python 3.10 と `requirements.txt` の3パッケージを使う。GPU・CuPy・PBS は不要。

`run_sample.py` は `# %%` で区切ってある。IPython / VS Code では上から順にセル実行し、
「設定」セルを編集・実行した後、最後の実行セルを再実行する。図はセルにも表示する。

## 処理と既定値

1. `InputData/phase_equation.npz` から結合関数、`c, omega, L`、ノイズ係数 `C` を読む。
2. Euler–Maruyama 法で `[Phi1, Theta1, Phi2, Theta2]` の非折り返し位相を生成する。
3. 保存した隣接時点の中点・差分を作り、位相差平面の各セルから重複なしで抽出する。
4. 複素Fourier基底と発散補正を用いたバッチMAP推定を、系1・系2について実行する。
5. 推定値、ノイズ共分散、収束判定、比較図、データ量と処理時間を保存する。

| 設定 | 既定値 |
| --- | --- |
| 結合強度 `epsilon` | `1e-6` |
| ノイズ強度 `sigma` | `1e-6` |
| 積分刻み `dt` / 終了時刻 | `0.05` / `1000` |
| 保存間隔 | 20ステップ、`Delta_t = 1.0` |
| 初期条件 | 空間16 × 時間8 = 128軌道 |
| 前処理前の増分 | 128,000点 |
| 推定次数 `Ms, Mt` | `4, 2`（45モード、2成分で90係数） |
| 抽出 | 16 × 16セル、各セル最大100点 |
| 固定事前分布 | `a_prior=0`, `Xi_prior=1e-6 I` |
| 最大反復 / 収束判定 | 50回 / 係数と共分散の相対変化がともに `1e-5` 未満 |

これは短時間で一連の処理を確認するための設定。論文本体の軌道長・データ量・次数
`Ms=20, Mt=5` を再現する設定ではない。次数を上げる場合は、それを解像できる数の
初期位相と推定サンプルも用意する。保存間隔と積分刻みは別であり、差分には保存間隔 `Delta_t` を使う。

生成・推定を分ける場合：

```sh
python 推定サンプルプログラム/run_sample.py --stage generate --output-dir /tmp/phase_sample
python 推定サンプルプログラム/run_sample.py --stage estimate --output-dir /tmp/phase_sample
```

推定だけを再実行する場合、同じ `estimation_data.npz` を使用する。方程式ファイルも生成時と同じものを指定する。

## 出力

既定の保存先は `output/`。

| ファイル | 内容 |
| --- | --- |
| `sde_data.npz` | 全128軌道、時刻、生成条件、真の共分散、入力の出典 |
| `estimation_data.npz` | 4中点位相＋4差分速度、`Delta_t`、生成条件 |
| `estimated_phase_equation.npz` | 両系の係数、精度行列、ノイズ共分散、推定ドリフト、収束履歴 |
| `phase_equation_comparison.png/.pdf` | 系1の非定数部分：入力・推定・差分 |
| `summary.json` | サンプル数、8配列のバイト数、処理時間、収束、誤差、生成条件 |

比較図は定数項を除いている。図に対応するノルム誤差と定数項の推定値も `summary.json` に保存する。
SDE全出力の点数、推定に選んだ増分数、推定中の作業行列のメモリ量は、それぞれ異なる。

## Xi_prior / Xi_old と、今回確認した修正

同じデータを繰り返し使うバッチMAPでは、各反復で使う事前分布は固定する。

```python
Xi_new = Xi_prior + Delta_t * sum(G_H @ inv(E) @ G)
r = Xi_prior @ a_prior + Delta_t * sum(G_H @ inv(E) @ dot_chi) \
    - Delta_t / 2 * sum(partial_G_H @ ones)
a_new = solve(Xi_new, r)
```

- **`Xi_old` を加算し続けない。** 同じデータの尤度を反復回数だけ重複して数えることになる。
  旧履歴にはこの実装があったが、現在の元コードはすでに `Xi_prior` を使っている。
- **右辺は `Xi_prior @ a_prior`。** 現在の元CPU/GPUコードは `Xi_prior @ a_old` となっている。
  これは固定した事前平均を毎回前回推定値へ動かすことになり、上記のバッチMAPと異なる。
  このサンプルでは固定した事前平均に修正した。
- **ノイズ共分散は最新係数の残差で更新する。** 係数とノイズの両方の収束を確認する。
  最終係数の条件付き精度行列に使った共分散も `noise_for_last_coefficient_update` に保存する。
  未収束で止めたときは、保存した最終残差共分散と一致するとは限らない。
- **周期端のセルも抽出する。** 元の間引きは上端 `+L, +pi` を下端へ折り返してから区間判定し、
  最終行・列のセルを空にしていた。このサンプルでは周期ビンの上端を保持する。

異なる新しいバッチを逐次取り込む場合に、前バッチの事後分布を次の事前分布へ渡す処理とは区別する。
元コードの既定事前精度は `1e-6 I` と弱いため、右辺の修正が既存論文結果へどの程度影響するかは
このサンプルだけでは評価していない。

`bayes_cpu.py` は巨大な `G` / `partial_G` テンソルを作らず、Fourier特徴行列と十分統計を使う。
共分散には固有値の下限 `noise_floor=1e-14` を設け、適用回数を結果に保存する。

## 同梱した方程式の出典

`InputData/phase_equation.npz` は約1 MBで、次のリポジトリ内データから作成した。

- `PhaseEquation/CouplingFunction_8193.npz` の `Gamma_s, Gamma_t`：2049 × 2049格子を8点刻みで抽出し、257 × 257格子にした。周期端点は保持する。
- `PhaseEquation/freq_8193.npz` の無ノイズの `c, omega`。
- `SRC_論文改訂チェック用_ベイズのチェック/InterimData/theoretical_sde_constants.npz` の `C`。

各系のノイズ共分散は `E = sigma**2 * C`、両系のノイズは独立とする。
元の検証コードが使うノイズによる周波数シフトのCSVは、このサンプルでは使用しない。
出典ファイルのSHA256、元の格子形状、抽出幅は同梱NPZの `metadata_json` に保存している。
同梱モデルを使う通常実行では、元の大容量ファイルやES4への接続は必要ない。

## 検証

```sh
python -m unittest discover -s 推定サンプルプログラム/tests -v
```

非零・強い事前分布での解析解、同一バッチの重複加算防止、直接構成した複素 `G` との一致、
既知のFourierドリフトの回復、SDEの再現性、周期端セル、中点の折り返し順序を確認する。
